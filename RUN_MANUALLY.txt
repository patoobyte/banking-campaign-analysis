RUN MARKET SIGNAL WITHOUT THE .BAT FILES
========================================

Open PowerShell inside this extracted project folder.

FIRST INSTALLATION
------------------
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env

Set NAVY_API_KEY in .env, save the file, then continue.

START THE APPLICATION
---------------------
.\.venv\Scripts\Activate.ps1
python -m streamlit run app.py --server.port 8501

Open http://localhost:8501.

If PowerShell blocks Activate.ps1, activation is optional. Use the environment Python directly:

.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --server.port 8501

MAIN PYTHON ENTRY FILE
----------------------
app.py

Do not run agent_backend.py, backend.py, or persistent_browser.py directly. They are support modules loaded by app.py.

STOP
----
Press Ctrl+C in the terminal that is running Streamlit.
