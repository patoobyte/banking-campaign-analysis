MARKET SIGNAL TROUBLESHOOTING
=============================

SETUP WINDOW CLOSES OR FAILS
1. Open Command Prompt.
2. Use cd to enter the extracted project folder.
3. Run: setup_windows.bat
4. The window stays open and shows the failing command.
5. See RUN_MANUALLY.txt for manual commands.

PYTHON NOT FOUND
Install Python 3.11 from https://www.python.org/downloads/ and enable “Add python.exe to PATH”.

CHROME NOT FOUND
Install desktop Google Chrome from https://www.google.com/chrome/.
Chrome DevTools MCP and Node.js are not required.

API ERROR
Open .env and verify:
NAVY_API_KEY=your-real-key
NAVY_BASE_URL=https://api.navy/v1
NAVY_MODEL=gpt-5.6-luna

CHROME PROFILE LOCKED
Stop Market Signal. Close automated Chrome processes/windows, then retry. If necessary, delete data\chrome-profile. Do not delete your personal Chrome profile.

PORT 8501 IS ALREADY IN USE
Close the previous Market Signal terminal or press Ctrl+C there. Alternatively run:
.\.venv\Scripts\python.exe -m streamlit run app.py --server.port 8502

AGENT INTERACTION FAILS
A failed click should be recoverable. If the full run fails, read agent_error.log. Increase the tool-step budget, keep visual analysis enabled, and retry.

PAGE COUNT IS LOWER THAN THE SLIDER
The slider is a maximum, not a guaranteed target. The agent follows relevant discovered URLs and respects allowed domains and robots.txt.

RESET LOCAL RESEARCH DATA
Stop the app first. Generated data can be removed from data\campaigns.db, data\chrome-profile, screenshots, and reports. This is irreversible for local history.
